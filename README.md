# Видео-квиз «Логорио»

Видео-квиз по ТЗ 1.1. Восемь блоков с видео и двумя вопросами, сохранение черновика, проверка и отправка ответов для разбора сотрудником.

Опубликованный сайт: [Видео-квиз «Логорио»](https://tavabilov.github.io/logorio-video-quiz/).

## Публикация на GitHub Pages

Статическая версия собирается командой `npm run build:pages`. Переменная `GOOGLE_RECEIVER_URL` задаёт адрес развёрнутого Google Apps Script `/exec`; инструкция и исходники приёмника находятся в `integrations/google-apps-script/`. Идентификатор закрытой таблицы хранится только в свойствах скрипта Google, в публичные файлы не включается. Без приёмника отправка показывает ошибку и сохраняет черновик.

Результат сборки — `dist/`. Для публикации его содержимое помещается в `docs/`; GitHub Pages настраивается на ветку `main`, папку `/docs`. Базовый путь — `/logorio-video-quiz/`.

GitHub Pages отправляет анкеты в закрытую Google Таблицу. Успех показывается после подтверждения записи; повтор не создаёт дубль. Публичная версия не включает серверный кабинет и редактор. Материалы меняются в `content/quiz.json`, после чего нужно обновить также согласованную версию приёмника, пересобрать и опубликовать сайт.

Локальная серверная версия ниже сохраняет анкеты в SQLite и дополнительно включает защищённый кабинет и редактор. Эти функции требуют отдельного сервера.

## Открыть

После запуска: [видео-квиз](http://127.0.0.1:4173) · [кабинет](http://127.0.0.1:4173/admin).

Для запуска нужен Node.js 24 или новее. В папке проекта выполните `npm install`, затем `npm start`. На Mac можно открыть файл `Открыть видео-квиз.command`. Сервер должен оставаться запущенным. Адрес доступен на этом компьютере; это ещё не опубликованный сайт для родителей.

Пароль кабинета создаётся автоматически при первом запуске и находится в приватном файле `data/admin-password.txt`. Не публикуйте папку data и этот пароль. Для развёртывания пароль задаётся защищённой переменной окружения; подробности в BACKEND.md.

## Как проверить

1. Откройте квиз и нажмите «Начать видео-квиз».
2. Запустите встроенное видео со звуком. Это собственный MP4, без YouTube/ВКонтакте.
3. Заполните 10 блоков вымышленными ответами. В актуальной клиентской анкете 77 вопросов с вариантами, условными уточнениями и отдельными полями. Можно возвращаться назад. После закрытия страницы продолжение доступно в этом браузере в течение семи дней с последнего изменения.
4. Проверьте ответы, укажите вымышленное имя и контакт (например, parent@example.test), отправьте.
5. Войдите в кабинет, откройте отправку, добавьте заметку и измените статус.

Одна и та же повторная отправка после сбоя связи не создаёт дубль. При ошибке соединения успех не показывается; ответы можно отправить ещё раз.

## Как менять материалы

В кабинете откройте «Видео и вопросы». Здесь можно редактировать оффер, инструкцию, темы блоков и формулировки, типы/варианты и обязательность вопросов. Блоки и вопросы можно добавлять, удалять и перемещать.

Для замены видео выберите MP4 (до 100 МБ) в нужном блоке. Загрузка идёт в собственное хранилище проекта. Предпочтительный формат — H.264/AAC с fast start. Проверка контейнера не заменяет проверку воспроизведения конкретного файла.

«Сохранить черновик» не меняет квиз для посетителей. «Предпросмотр» открывает сохранённый черновик и не отправляет ответы. «Опубликовать версию» обновляет квиз на локальном сервере; это не публикация в интернете. Начатые попытки сохраняют исходную версию. Ранее отправленные ответы и тексты вопросов не меняются.

Смена обложки поддерживает путь к изображению в public (например, /poster.svg). Загрузка новых изображений через кабинет не реализована; файл кладётся в public при наполнении.

## Что пока демонстрационное

Видео — собственная нейтральная десятисекундная заглушка с тихим звуковым сигналом. Вопросы — предварительные примеры, не диагностическая методика. Логотип, цвета, графика и типографика перенесены из предоставленной визуальной концепции «Логорио». Shadow взят из оригинального веб-пакета автора и сверен с буквами в PDF; Montserrat размещён локально. Автоматических диагнозов или рекомендаций нет.

Для настоящего запуска нужно утвердить вопросы, оффер, контакты и документы об обработке данных, добавить готовые ролики, согласовать сроки хранения/разбора и доступ сотрудников, выбрать сервер и домен с HTTPS. До этого интерфейс просит использовать только тестовые данные. Физические iPhone/Android не проверялись; браузерные проверки выполнены в Chromium и WebKit на мобильных размерах.

## Проверки и обслуживание

- `npm test` — серверные проверки доступа, отправки, версий, загрузки и восстановления.
- `npx playwright install chromium webkit`, затем `node scripts/verify-browser.mjs` — полный браузерный сценарий в изолированной временной базе, без изменений рабочих отправок.
- `npm run backup` — копия базы и загруженных файлов.
- `npm run restore -- /путь/к/копии` — восстановление при остановленном сервере с учётом журнала удалений; подробно в BACKEND.md.

Результаты браузерных проверок и скриншоты находятся в `.impeccable/review/`. Контакты и ответы в технические журналы не пишутся. Папки data и backups не предназначены для публикации.

Исходные требования: «ТЗ — Видео-квиз Логорио.md». Реестр демонстрационных материалов: ASSETS.md. Сервер и размещение: BACKEND.md.

## Мобильные подсказки и анимация

Кнопка в нижней панели ведёт к ответам, затем к следующему блоку. Мини-персонажи показывают текущую задачу; выбор ответа и переход имеют короткую обратную связь. Подробные вопросы к видео и список глав раскрываются по запросу. На финальном экране контакты доступны сразу, ответы можно раскрыть для проверки. Режим уменьшенной анимации поддерживается.

`node scripts/verify-guided-flow.mjs` проверяет направляемый сценарий на мобильных размерах в Chromium/WebKit. Аудит и ограничения записаны в «Аудит мобильного квиза.md».
