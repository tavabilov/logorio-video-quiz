# Получатель ответов в приватную Google Таблицу

Создайте Apps Script, добавьте `Code.gs`, HTML-файл `Bridge` и манифест `appsscript.json`. В настройках проекта → свойства скрипта задайте `SPREADSHEET_ID` приватной таблицы. Доступ к таблице посетителям сайта не предоставляется.

`INITIAL_QUIZ` содержит исходные вопросы версии 1. Необязательное свойство `QUIZ_VERSION_1` — полный JSON этой же опубликованной версии; после начала приёма оно неизменно. Новую версию требуется добавить отдельно в серверную проверку и публичный квиз. Не подставляйте текущий изменяемый черновик вместо опубликованной версии. `NEXT_SUBMISSION_NUMBER` создаётся автоматически; не уменьшайте счётчик.

Разверните **веб-приложение**, выполнение от владельца, доступ «Все». Google запросит разрешение владельца на работу с таблицами. Впишите URL `/exec` в конфигурацию публичного сайта. После изменения кода обновите версию развёртывания. Не размещайте идентификатор приватной таблицы, токены или учётные данные в клиентском коде.

Лист `Ответы` содержит 25 колонок: номер, дата (Москва), имя взрослого, контакт, статус, заметка сотрудника, версия квиза, ключ отправки, ответы JSON и 16 ответов. При пустом листе заголовки создаются автоматически. Существующий лист должен сохранять этот порядок; JSON содержит согласие, проверенные вопросы, ответы и хеш повторной отправки. Число выдаётся независимо от номера строки. Произвольные строки, способные стать формулой, экранируются.

## Протокол подтверждения

Сайт `https://tavabilov.github.io` создаёт iframe с URL `/exec?channel=<случайный nonce>`. В URL нет ответов и контактов. Bridge отправляет в `window.top` сообщение `{type:'logorio:ready',channel}`. Родитель проверяет nonce и сохраняет `event.source` и фактический Google origin. Отправка направляется именно этому окну и origin:

```js
{type:'logorio:submit',channel,requestId,payload:{key,version:1,name,contact,consent:true,answers}}
```

`channel` и `requestId` — 8–100 символов `[A-Za-z0-9_-]`. Bridge принимает сообщения только от `window.top` и точного origin сайта. Google HTML Service может добавлять sandbox iframe: используйте `event.source` из handshake, не предполагая совпадение с внешним `iframe.contentWindow`.

После блокировки, проверки, записи, `SpreadsheetApp.flush()` и чтения сохранённой строки сервер возвращает квитанцию; Bridge отправляет `{type:'logorio:receipt',channel,requestId,id,number}`. Только такая квитанция означает успех. `{type:'logorio:error',channel,requestId,error}` либо таймаут сохраняют черновик и позволяют повторить тот же ключ. Результат непрозрачного `fetch(...,{mode:'no-cors'})` не является подтверждением.

Повтор идентичной нормализованной отправки возвращает тот же номер без новой строки. Другие данные с прежним ключом отвергаются. Общедоступных функций чтения таблицы и ответов нет. Endpoint открыт для отправки; nonce и origin защищают связь окон, но не служат авторизацией или защитой от автоматического спама. Ограничения квот Google сохраняются. Проверка на реальном `/exec` нужна после развёртывания; локальный тест не подтверждает доступность веб-приложения.

Проверка: `node --test tests/google-receiver.test.mjs`.
